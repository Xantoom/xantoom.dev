### Looping video (like a GIF)

GIFs are often 10 times heavier than a video. Put a `.webm` or `.mp4` file in `public/media/` and use:

```mdx
<Video src="/media/demo.webm" gif alt="Description of the animation" />
```

## Code

```ts title="example.ts"
// Frame time at a given refresh rate.
export function frameTime(hz: number): number {
  return 1000 / hz;
}

console.log(frameTime(240).toFixed(2)); // 4.17 ms
```
